# CICan Microgrants Website

A modern, responsive web application built to showcase impact climate projects, featuring full localization support and a clean UI.

## 🚀 Tech Stack

* **Framework:** [React](https://reactjs.org/)
* **Language:** [TypeScript](https://www.typescriptlang.org/)
* **Styling:** [Tailwind CSS](https://tailwindcss.com/)
* **UI Components:** [shadcn/ui](https://ui.shadcn.com/)
* **Animations:** [Framer Motion](https://www.framer.com/motion/)
* **Generation Tool:** [Lovable](https://lovable.dev/)

## 📁 Important File locations
* Main data file for colleges descriptions - ```/data/projects.json``` (english and french versions there)
* All projects images - ```/public/projects```
* Translations for all other elements across the website - ```/i18n/en(fr)```
* Main brandings (link to pdf report in hero etc.) - ```/data/brandings.ts```

## 🛠️ Getting Started

Follow these steps to set up the project locally:

```sh
# Step 1: Clone the repository
git clone [https://github.com/Camperkunz/impact-climate-showcase](https://github.com/Camperkunz/impact-climate-showcase)

# Step 2: Navigate to the project directory
cd impact-climate-showcase

# Step 3: Install the necessary dependencies
npm install

# Step 4: Start the development server
npm run dev
```
